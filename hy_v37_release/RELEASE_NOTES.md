# 흥양기 v37.0.0 릴리스 노트

## 전면 개편

- 메뉴형 카드게임에서 생활 이동·조우·조사·금기 전투가 이어지는 내러티브 카드 RPG로 핵심 구조 교체
- 고흥 농촌 버스와 논길을 이용한 일상→이상 전환 구현
- 7개 살매듭과 실제 굿판의 시각 언어를 활용한 창작 보스전 구현
- 첫 사망이 도감 정보와 `명두` 카드 해금으로 이어지는 지식 성장 루프 구현
- 얼굴을 직접 보지 않고 반사·봉면하는 승리 규칙 구현
- 카드 능력과 보스 의도 간 파훼 관계 구현
- 1성~6성 동일 기본 원화, 최종 진화만 다른 서사 원화 규칙 적용
- 최종 카드가 프레임 밖으로 돌출되는 2.5D/CSS 3D 현신 연출 구현
- 다음 야행록으로 팔영산, 나로도, 남열, 거금도, 연홍도, 쑥섬 구상 연결

## 기술

- 단일 실행 HTML 제공
- PWA manifest와 service worker 제공
- 자동 저장·이어하기
- Web Audio 합성 장단과 모바일 햅틱
- 모션 감소 및 모바일 안전영역 대응
- 안전 설치·백업·롤백 도구 포함

- 데스크톱 4항목 통과

## 한계와 다음 전환

현재판은 규칙과 연출을 실제 플레이로 검증하는 웹 세로 슬라이스입니다. 최종 상용 3D판은 Unreal에서 버스 필드, 신목 굿청, 무당 Control Rig, Chaos Cloth, 응시 판정, 카드 포털 현신을 실시간 시스템으로 교체합니다.
