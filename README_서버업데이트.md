# 흥양기 v38 서버 주도 업데이트 패키지

이 패키지는 흥양기 UI v6에 다음을 추가한다.

- `main` 푸시 기반 GitHub Pages 자동 배포
- 실행 중 최신 버전/커밋 감지
- 안전 화면 자동 업데이트, 시네마틱/전투 업데이트 잠금
- 업데이트 전 진행 기록 백업
- 버전별 서비스워커 캐시와 오프라인 재실행
- Supabase Edge Function 자동 배포
- 서버 상태, 최소 지원 버전, 점검/강제 업데이트 정책
- 운영자용 배포 상태 페이지
- 자동 설치·백업·롤백 도구

빠른 시작은 `docs/live-update/README_설치배포.md`를 따른다.
