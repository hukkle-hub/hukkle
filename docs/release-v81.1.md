# 흥양기 v81.1 — 칠매듭 판 보스전

## 적용 범위

- 기존 dungeon-flow.html 내부 스코프에 판 전투를 통합했다.
- 메인 화면의 탐험 iframe 경로는 유지하고 중첩 iframe 삽입 경로는 제거했다.
- 올바른 대응은 보스 행동을 취소하고 매듭 하나를 푼다. 일곱 매듭 해제로 승리한다.
- 첫 대면은 오답에도 결계 피해가 없고, 재도전은 반격과 패배가 적용된다.
- 기세 5단계의 최고조에서 실제 장착된 7성 동행자가 자동 현현해 전장에 남는다.
- 카드 스킬 메타데이터와 대응 역할을 연결했다. 덱에 없는 대응만 아인의 기본 행동으로 보충한다.
- 탐험 저장, 반복 승리 보상, 메인 복귀 메시지 체계는 유지했다.
- 기존 v81 프로토타입 URL은 정식 탐험 화면으로 이동한다.

## 회귀 검수

- qa:mobile: 시작 화면, 50회 화면 전환, 상점, 카드, 저장 및 직접 메인 복귀.
- qa:yeojaman: 이동, 단서 3개, 던전 7지점, 칠매듭 승리와 저장.
- qa:combat: 5지역 첫 대면 보호, 매듭 승리, 자동 현현, 재도전 반격과 패배, 메인 탐험 연결.
- 결과와 화면 캡처는 각 qa 디렉터리 및 GitHub Actions QA artifact에 생성된다.

이번 통합은 첨부된 기존 캐릭터·배경·FX 아틀라스를 사용한다.
