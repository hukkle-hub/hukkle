# 흥양기 v85 카드 공방

첫 대면은 보스 얼굴을 보여주지 않는 기척 탐사다. 지역 풍경과 물음표 카드를 보여주며 잘못 대응해도 피해를 받지 않는다. 일곱 매듭을 기록하면 기존 첫 완료 저장과 보상 절차로 이어진다.

완료 기록이 있는 지역의 다음 대면부터 보스가 모습을 드러낸다. 보스 공격 카드 → 플레이어 대응 카드 → 받아치기 또는 결계 피격의 순서로 한 번의 공방을 처리한다. 기록·수호·파훼 선택이 실제 판정과 연결된다. 적절한 대응은 공격을 막고 매듭 하나를 풀며, 잘못된 대응은 반복전 결계 피해와 기세 하락으로 이어진다.

전신 포즈 이동과 전체 화면 섬광을 사용하지 않는다. 장착한 카드 다섯 장, 실제 남은 매듭, 결계와 기세를 표시한다. 7성은 장착 동행자의 최종 이미지와 기술명으로 컷인을 보여준다. 가짜 HP·마나·피해량은 표시하지 않는다. 전투 중에는 자동 업데이트를 적용하지 않는다.

검수: qa:mobile(50회 화면 이동 및 기능), qa:yeojaman(탐사부터 보상까지), qa:combat(5지역 첫 대면/재대면/패배/저장/iframe), qa:cinematic(카드 공방, 첫 얼굴 숨김, 1280×720/960×540/844×390/667×375 터치, 현현, 직접 나가기).
