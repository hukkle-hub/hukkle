# 흥양기 v89 — 재대면 층 구도 (묶음 2)

결정 D1(층 구도) · D3(보스 정지)에 따라 재대면 화면을 층으로 나눴다. 첫 대면(기척 탐사)은 v85 카드 화면 그대로다.

## 층 순서 (`admin/card-battle-v85.js` · `.cb-stage`)
먼 띠 → 안개(뒤) → 중간 띠 → **보스(제자리)** → 합 공간 → 가까운 띠 → 안개(앞) → 동행자(아인 뒤 왼쪽) → **아인** → 효과 → HUD

- 배경은 그림 한 장을 먼·중·근 띠 3장으로 나눠 겹쳤다. 화면비가 달라도 띠가 어긋나지 않도록 ResizeObserver로 맞춘다.
- 보스: v82 원화의 정지 자세만 쓴다. 맞으면 명멸만 한다 (D3).
- 아인: v82 원화 6자세. 대기 · 맞서기(던지기) · 지키기 · 끊기(치켜듦) · 버티기 · 피격.
- 합: 손패 카드와 보스의 수가 양쪽에서 날아와 아인과 보스 사이에서 부딪힌다. 진 쪽은 framebreak 아틀라스로 부서지고, 이긴 쪽이 관통한다.
- 강신: 컷인 뒤 해신 당골이 아인 뒤 왼쪽에 남고, 동행 카드를 낼 때 시전 자세로 바뀐다.
- 전투 기록은 보스를 가리지 않도록 오른쪽 기둥(예고 아래)으로 옮겼다.
- 효과: burst · framebreak · rise · fog. 모두 구운 이미지이고 CSS 도형은 쓰지 않는다.
