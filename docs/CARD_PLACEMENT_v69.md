# 흥양기 125종 배치 원칙 · v69

## 획득 구조

125종을 한 화면이나 한 던전에 동시에 늘어놓지 않는다. 지역·난도·이야기 진행에 따라 아래 풀에서 순환한다.

| 분류 | 수량 | 배치 방식 |
|---|---:|---|
| 일반 조우 | 45 | 지역 1~2단계, 반복 탐험 |
| 정예 수호자 | 30 | 지역 3단계, 약점·BREAK 학습 |
| 네임드 | 25 | 지역 5단계, 금기와 선택 기록 |
| 장 보스 | 10 | 장 마지막 전투와 확정 기록 |
| 숨은 의례 | 10 | 조건부 갈림길·재탐험 |
| 제작 전용 | 5 | 탐험 드롭 없음, 재료 제작 |
| 합계 | 125 | |

## 현재 5개 지역의 첫 순환 풀

각 지역은 `일반 조우 → 갈림길 → 정예 수호자 → 의례 준비 → 네임드 관문 → 장 보스` 순서로 진행한다. 첫 순환에는 지역별 5장, 총 25장이 배치되며 나머지는 난도와 이야기 장이 열릴 때 교대한다.

- 여자만: 갯것, 물비늘, 그물귀신, 넋건지기 무녀, 여자만 용녀
- 녹동항: 도깨비불, 서낭, 수부 사공, 장시 사람, 용왕차사
- 팔영산: 당산나무, 산지기, 벅수장군, 산신동자, 여산신
- 거금도: 조개무지, 간재미, 거북사자, 미역할미, 개양할미
- 나로도: 해무, 물귀신, 청룡, 해신 당골, 나로의 물결

## 최상위 제작 전용 5종

기본 전투력 순위 최상단을 제작 전용으로 묶는다.

- 달걀귀신 — 기본 전투력 164
- 미르(용왕) — 기본 전투력 164
- 별상(장군) — 기본 전투력 164
- 조왕각시 — 기본 전투력 164
- 액(厄) — 기본 전투력 157

이 다섯 카드는 카드 화면의 `제작` 탭에서만 획득한다. 제작 전에는 보유 카드, 탐험 동행, 파티 편성, 자동 편성에 나타나지 않는다. 금줄·황토 세 줌·정화수·지전·신칼은 다시 일반 획득 카드로 유지한다.

## 전투 연계

- 일반 조우는 관찰 또는 정면 대응을 고른다.
- 갈림길은 안전과 추가 보상의 선택을 남긴다.
- 정예는 파훼와 수호의 대응을 학습한다.
- 의례는 결계 회복 또는 현현 공명을 준비한다.
- 네임드는 금기를 확인한 뒤 장 보스를 연다.
- 장 보스는 행동 예고에 맞춰 공격·파훼·수호를 고르고 공명 100에서 7성 현현을 사용한다.
