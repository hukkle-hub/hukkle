# 흥양기 v86 — 재대면 판 공방

2026-10-14 시안(판 보스전 시안)의 규칙을 `admin/dungeon-flow.html`에 직접 옮겼다. 첫 대면(기척 탐사)은 v85 그대로다.

## 규칙
- 보스의 수: 이름 · 징조 · 종류(힘/부름/환영)만 표시한다. 어떤 카드로 꺾는지는 적지 않는다.
- 처음 보는 수(둘째 국면부터)는 「? 부름 또는 환영」처럼 두 종류로만 보인다. 한 번 겪으면 지역 저장(`panRecorded`)에 기록된다.
- 상성: 맞서기 ▶ 힘 · 지키기 ▶ 부름 · 끊기 ▶ 환영.
- 카드 쉼(등급 = 현재 별에서 쓰는 기술의 grade): 일반·희귀 0수 / 영웅 1수 / 전설 2수. 매듭 힘: 전설 2, 나머지 1.
- 매듭: 1·1·1 → 겹매듭 2·2·3 → 마지막 매듭. 한 합에 매듭 하나까지만 풀린다.
- 판의 기세 상한: 첫째 판 2 · 겹매듭 3 · 마지막 매듭 4. 마지막 매듭에서 최고조에 닿는 합을 이기면 7성 동행자가 강신해 공수로 결착한다. 7성이 없으면 아인의 기록으로 결착한다.
- 추임새: 이긴 직후 선택. 기세 +1, 대신 다음 수가 강수(피해 ×1.6, 받아치면 매듭 힘 +1).
- 아인 버티기: 피해 1/3, 기세 변화와 진전 없음.
- 지역 장단: 녹동항만 물때(4수마다 기세가 가운데 2로 끌려감). 나머지 네 지역은 다음 단계.
- 피해: 보스 수 피해 × 0.65 (강수 ×1.6, 버티기 ×1/3).

## 검수
`npm run qa:repeat` — 5지역 × (정석 4판 + 무작위 2판).
- 답 노출 문구 0, 쉬는 카드 클릭 0, 마지막 매듭 전 기세 3 이하, 승리는 항상 강신으로 끝남, 새 수 기록 저장.
- 2026-10-14 측정: 정석 20/20 승, 9~12수, 결계 31~100 잔존 / 무작위 0/10.
