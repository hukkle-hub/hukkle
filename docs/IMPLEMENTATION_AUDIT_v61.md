# 흥양기 기획 대비 구현 감사 v61

기준 문서: `흥양기_기획정본_v3_전면개편.md`, `IMPLEMENTATION_REPORT.md`, `HEUNGYANGGI_MOBILE_REBUILD_V43.md`.

## 구현 완료

- 1280×720 단일 게임 화면과 모바일 비율 축소
- 지도, 인벤토리, 카드, 도감, 파티, 상점, 임무의 주요 화면 전환
- 125종 카드 데이터와 1~6성 성장 데이터 구조
- 여자만을 포함한 지역 이동 → 현실 탐사 → 단서 관찰/검증/기록 → 이면 조사 → 보스 발견 흐름
- APK가 서버의 GitHub Pages를 여는 thin WebView 구조 및 자동 빌드 워크플로
- 저장 데이터, 아이템 소비, 동행 카드와 탐사 iframe 간 메시지 연결

## 일부 구현

- 최종현현: 카드 UI와 연출 구조는 있으나 125종 개별 최종현현 그림은 미완성
- 전투/금기 보스: 대표 흐름과 데이터는 있으나 모든 지역·보스가 같은 깊이로 제작되지는 않음
- 카드 미술: 해신 당골, 여자만 용녀, 오관대왕을 신규 고유 일러스트로 교체. 나머지 미제작 인물은 얼굴 복제 대신 카드별 고유 문양을 표시
- 지역 탐사: 다수 지역 데이터와 3단서 루프는 존재하지만 지역별 고유 퍼즐·분기·보상 다양성은 추가 제작 필요

## 아직 제작이 필요한 큰 항목

- 125종 모두의 개별 기본 일러스트와 별도 최종현현 일러스트
- 125종 × 6단계에 대응하는 실제 전투 밸런스·연출의 전수 제작 및 플레이테스트
- 7매듭 금기 보스 전체 캠페인, 죽음→지식 계승, 거울 해금, 장기 의례 시퀀스의 완전한 캠페인화
- 서버 계정, 클라우드 저장, 운영 이벤트, 결제·상점 백엔드
- 접근성, 저사양 기기, 다양한 Android WebView 버전의 실기기 회귀검사

## v61에서 바로잡은 항목

- 첫 이야기 진입 시 자동으로 재생되던 지도·수납 영상을 제거
- 설정의 소리 토글이 배경 영상을 음소거 해제하던 문제 제거
- 탐사 이동을 자동 영상 대신 명시적인 구간 버튼 진행으로 변경
- 탐사 순서를 `단서 선택 → 기본 관찰 → 추천 도구 검증 → 기록 확정`으로 상시 표시
- 부모 화면의 지도 버튼, 탐사 위치판, 단계판, 조사 시트가 겹치지 않도록 재배치
- 우측 상단에 떠 있던 업데이트 점을 숨기고 게임 조작 영역을 보존
