## 발견·수정한 문제

### 숨겨진 카드 기록 버튼 선택 문제

여러 장면에 공통 헤더 버튼이 존재해 자동화가 첫 번째 숨겨진 버튼을 선택했습니다. 실제 활성 장면의 버튼으로 범위를 제한하도록 QA 선택자를 수정했습니다.

### 모바일 굿판 상단 겹침

작은 화면에서 장 제목과 전투 HUD가 겹칠 수 있어 모바일 굿판에서는 장 제목을 숨기고, 전투 정보만 남겼습니다.

### 파일 직접 실행 저장 예외

일부 제한된 브라우저 환경에서 localStorage 접근이 거부될 수 있어 저장 함수가 예외를 삼키고 플레이를 계속하도록 보강했습니다.
