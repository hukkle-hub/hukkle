# 흥양기 v37 전면 개편 구현 보고서

## 1. 개편 목표

기존의 허브·도감·버튼 중심 카드게임 화면을 덧붙이는 방식에서 벗어나, 플레이어가 고흥의 생활 공간을 이동하다 설명할 수 없는 존재를 만나고, 죽음으로 규칙을 배우며, 카드와 의례로 사건을 해결하는 현대적인 내러티브 카드 RPG의 핵심 루프를 구현했습니다.

이번 버전의 단일 사건 흐름은 다음과 같습니다.

```text
타이틀
→ 농촌 버스 이동
→ 일곱 단계의 이상 징후
→ 무표지 정류장 하차
→ 논길 현장 조사
→ 신목 굿청 진입
→ 7매듭 금기 보스전
→ 첫 응시 사망
→ 사망 도감과 명두 해금
→ 지식 기반 재도전
→ 봉면 의례
→ 최종 카드 현신
→ 다음 고흥 야행록
```

## 2. 구현된 장면

### 2.1 타이틀과 이어하기

- 신규 시작과 기존 기록 이어하기
- 진행 상태에 따른 이어하기 표기
- 사운드, 모션 감소, 기록 초기화
- 모바일 안전영역 대응

### 2.2 버스 이동

- 창밖 논, 수로, 낮은 산, 전봇대가 반복 이동하는 절차형 풍경
- 좌석, 손잡이, 창문 반사, 안내 방송을 이용한 실제 이동 감각
- 같은 허수아비가 반복 출현
- 벼가 바람 반대로 쓰러짐
- 라디오 문장 반복
- 승객과 창문 반사의 불일치
- 존재하지 않는 정류장 안내
- 하늘이 빠르게 어두워진 뒤 무표지 논길 정차

### 2.3 논길 조사

세 개의 단서를 직접 눌러 기록합니다.

- 물웅덩이: 실제 공간에 없는 얼굴의 반사
- 끊어진 볏짚 줄: 안쪽에서 바깥쪽으로 터진 경계
- 버스표: 존재하지 않는 정류장명

세 단서를 모두 찾으면 멀리 보이던 신목으로 이동할 수 있습니다.

### 2.4 금기 굿판 보스전

- 신목, 금줄, 7개 살매듭, 촛불, 지전, 무당, 얼굴을 가린 보스
- 실시간 장단 타이머와 합성 북소리
- 카드 비용, 신력 회복, 쿨다운, 장단 정타 보너스
- 매듭 장력, 굿청 안정도, 보스 봉인 잔량, 영험, 부정 상태
- 보스가 가까워질수록 크기·화각·환경음·촛불 상태 변화
- 실패 시 매듭 파열과 접근 단계 증가

보스 의도와 대응 카드:

| 보스 의도 | 대응 카드 | 효과 |
|---|---|---|
| 매듭 침식 | 금줄 | 매듭 장력 회복 및 침식 파훼 |
| 부정 번짐 | 정화수 | 부정 제거 및 유효 피해 |
| 살기 베기 | 신칼 | 살기 절단 및 높은 파훼 피해 |
| 경계 넘기 | 벅수 | 굿청 보호막 및 접근 저지 |
| 장단 삼키기 | 해신 당골 | 영험 축적 및 장단 회복 |
| 금기 응시 | 명두 | 직접 보지 않고 응시 반사 |

### 2.5 첫 사망과 도감

첫 도전에서는 명두가 잠겨 있습니다. 플레이어는 중간 응시를 피할 수 있지만, 보스의 육신을 파훼한 뒤 얼굴을 봉인하는 법을 몰라 결국 사망합니다.

사망은 실패 화면으로 끝나지 않습니다.

- 조우명 `논둑에서 따라온 것` 기록
- 마지막 남은 매듭 기록
- 금기: 진짜 얼굴과 시선이 맞닿으면 사망
- 명두 임시 신표 해금
- 재도전에서 새로운 카드 동사 추가

### 2.6 봉면 의례

육신 파훼 후 공격 버튼이 사라지고 의례 순서 퍼즐로 전환됩니다.

```text
금줄 → 정화수 → 명두 → 신칼 → 해신 당골
```

- 순서가 맞으면 봉면 단계 전진
- 순서가 틀리면 보스가 접근하고 단계가 후퇴
- 세 번 틀리면 다시 사망

### 2.7 최종 카드 현신

- 카드가 Y축으로 기울고 공간 깊이가 열림
- 기본 프레임이 갈라지고 최종 원화가 프레임 위로 돌출
- 인물의 머리·장식·물결이 카드 경계 밖으로 나옴
- 광원, 수막, 금색 문양, 파티클, 카메라 이동 결합
- 현신한 해신 당골이 보스의 얼굴을 다시 덮는 서사적 마무리

현재는 CSS 3D와 2.5D 레이어를 이용한 작동 시제품이며, Unreal판에서는 메시 포털과 실시간 캐릭터로 교체합니다.

### 2.8 진화 카드 규칙

사용자가 확정한 규칙을 게임 안에서 직접 검증할 수 있게 카드 기록 화면에 구현했습니다.

- 1성~6성: 동일한 기본 얼굴·포즈·배경 원화
- 단계 차이: 프레임 재질, 깊이, 별 문양, 입자, 홀로그램, 미세 현동
- 최종 진화: 완전히 다른 서사 원화와 현신 연출

자동 검수에서 1성과 6성의 이미지 소스가 동일하고, 6성과 최종 이미지 소스가 다름을 확인했습니다.

## 4. 기술 구성

- 외부 라이브러리 없는 단일 페이지 애플리케이션
- 순수 HTML/CSS/JavaScript
- localStorage 자동 저장
- Web Audio API 기반 북·방울·파열음 합성
- Vibration API 기반 모바일 햅틱
- requestAnimationFrame 기반 장단·카메라·전투 루프
- CSS perspective/transform 기반 카드 현신
- PWA manifest와 service worker 오프라인 캐시
- 모바일 412×915, 데스크톱 1440×900 대응
- `prefers-reduced-motion` 및 게임 내 모션 감소 설정

## 5. 디버그·검수 API

```js
window.HY37.getState()
window.HY37.reset()
window.HY37.jump(scene)
window.HY37.finishClues()
window.HY37.unlockMirror()
window.HY37.debugDeath()
window.HY37.debugVictory()
```

이 API는 QA와 장면별 연출 검수에 사용하며, 상용 배포 시 개발 빌드에서만 노출하도록 분리해야 합니다.

## 6. 현재판에서 의도적으로 남겨 둔 범위

- 고흥 버스와 들녘은 최종 실사풍 메시가 아니라 절차형 2.5D 블록아웃
- 카드 현신은 CSS 3D 검증본이며 실시간 리깅 캐릭터가 아님
- 대표 보스 `낯금이` 1종과 대표 현신 카드 `해신 당골` 1종만 완전 루프로 연결
- 서버 권한형 전투, 계정, 상점, 결제, 길드, 멀티 기기 동기화 미포함
- 124종 전체 카드의 최종 현신과 6개 지역 야행록은 확장 단계

따라서 이 릴리스는 상용 완성판을 가장하지 않습니다. 다만 전면 개편 방향의 핵심 재미와 기술 위험을 실제 플레이로 검증할 수 있는 완결된 버티컬 슬라이스입니다.
