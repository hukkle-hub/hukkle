# 흥양기 v37 — 얼굴 없는 밤굿

고흥의 일상적인 이동 풍경에서 시작해 이상 징후, 현장 조사, 금기 굿판 보스전, 사망 도감, 지식 기반 재도전, 봉면 의례, 최종 카드 현신까지 하나의 사건으로 이어지는 플레이 가능한 세로 슬라이스입니다.

## 가장 빠른 실행

### 단일 파일 실행

`heungyanggi_v37_standalone.html`을 Chrome, Edge 또는 Android Chrome으로 엽니다.

- 별도 서버나 설치가 필요 없습니다.
- 카드 기본/최종 이미지를 파일 안에 포함합니다.
- 브라우저 저장소(localStorage)에 진행 상태를 저장합니다.
- 파일 직접 실행에서는 PWA 설치와 서비스워커 오프라인 캐시가 동작하지 않을 수 있습니다.

### PWA 방식 실행

`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `assets` 폴더를 같은 구조로 웹서버에 둡니다.

간단한 로컬 실행 예시:

```bash
python -m http.server 8777
```

그런 다음 브라우저에서 `http://127.0.0.1:8777`을 엽니다.

## 권장 플레이 순서

1. 새 야행록을 시작합니다.
2. 고흥 농촌 버스 안에서 반복되는 이상 징후를 확인합니다.
3. 논길에서 물웅덩이, 끊어진 줄, 버스표 단서를 조사합니다.
4. 신목 굿청으로 들어가 7개 살매듭을 지키며 장단에 맞춰 카드를 사용합니다.
5. 첫 도전에서는 얼굴의 법칙을 몰라 사망하고, 도감에서 `명두`의 사용법을 배웁니다.
6. 재도전에서는 `금기 응시` 예고에 명두를 사용합니다.
7. 보스의 육신을 파훼한 뒤 `금줄 → 정화수 → 명두 → 신칼 → 해신 당골` 순서로 봉면합니다.
8. 최종 카드가 프레임 밖으로 현신한 뒤 다음 고흥 야행록을 확인합니다.

## 조작

- 터치 또는 마우스: 선택, 조사, 카드 사용
- `시선 낮추기`: 명두가 없을 때 응시를 피하되 매듭 장력이 감소합니다.
- 장단 종료: 현재 유효 피해를 즉시 판정합니다.
- 카드 기록: 1성~6성의 동일 기본 원화와 최종 진화 원화 차이를 확인합니다.
- 메뉴: 사운드, 모션 감소, 기록 초기화

## 전투 읽는 법

- **7개 매듭**: 남은 페이즈이자 보스와의 거리입니다.
- **매듭 장력**: 0이 되면 매듭 하나가 끊어집니다.
- **굿청 안정도**: 무당의 생존 상태입니다.
- **봉인 잔량**: 보스 육신의 파훼 진행도입니다.
- **신력**: 카드를 사용하는 자원이며 시간에 따라 회복됩니다.
- **영험**: 장단에 맞춘 행동과 해신 당골 사용으로 축적됩니다.
- **보스 의도**: 금줄, 정화수, 신칼, 벅수, 해신 당골, 명두 중 어떤 대응이 필요한지 예고합니다.

## 저장과 초기화

저장 키는 `heungyanggi_v37_vertical_slice`입니다. 버스 단계, 조사 단서, 사망 횟수, 명두 해금, 승리 여부, 사운드/모션 설정을 자동 저장합니다.

게임 메뉴의 `기록 초기화`를 누르면 저장을 삭제하고 처음부터 시작합니다.

## 기존 저장소에 적용

배포 ZIP의 `apply_v37_patch.bat` 위로 기존 `hukkle` 저장소 폴더를 끌어다 놓습니다.

설치기는 다음을 자동 처리합니다.

1. 교체 대상 파일을 `_hy_backups/v37_날짜_시간`에 백업
2. v37 루트 시작 페이지와 PWA 파일 설치
3. 기존 카드 카탈로그와 `redraw` 폴더 보존
4. 파일 구조와 필수 게임 시스템 검사
5. 롤백용 설치 기록 생성

되돌릴 때는 `rollback_v37.bat` 위로 같은 저장소 폴더를 끌어다 놓습니다.

## 현재 구현 수준

현재판은 게임 규칙과 감정 흐름을 검증하는 **HTML/CSS/JavaScript 기반 플레이 가능한 세로 슬라이스**입니다.

- 버스와 들녘은 절차형 2.5D 연출입니다.
- 최종 현신은 CSS 3D, 레이어 돌출, 파티클, 카메라 이동으로 구현했습니다.
- 실시간 메시·천 물리·Control Rig·Niagara 기반 최종 3D는 `UNREAL_HANDOFF.md`의 구조로 Unreal에서 전환해야 합니다.
- 서버 권한형 계정 저장, 과금, 멀티 기기 동기화는 포함하지 않았습니다.
